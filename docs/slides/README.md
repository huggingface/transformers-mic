# MIC for Transformers maintainers

Open [index.html](index.html) in a browser. This is a 9-slide async reading guide
covering MIC's purpose, the automated model recipe, executable usage, assertions,
fast CPU checks in CI, how to respond to a failure, and proposed Hub discovery for agents.

All explanations appear in the slides; there are no speaker notes. The single
HTML file embeds its CI failure screenshot, has no runtime dependencies, and works offline.
Repository, Hub, and dashboard links require a network connection.

- Use the arrow buttons or arrow keys to navigate.
- **Contents** jumps to any slide; **Read all** shows the whole guide as a document.
- Links such as `index.html#slide-6` open a specific slide.
- Command blocks have copy buttons; placeholder values are labeled.
- **Contents → Print / save PDF** prints every slide.

Content checked on 22 October 2026 against MIC `main` at `748ed9d` and the local
Transformers CI dashboard documentation and controls. The deck distinguishes
the observational rollout from the broader proposal. The dashboard illustration
has no live data; the numeric example is explicitly historical.

Edit `index.html` directly. CSS, slides, and navigation are kept together so the
file can be shared independently. Keep each slide understandable without narration.
